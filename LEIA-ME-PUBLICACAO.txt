CULTURA TÉCNICA — PACOTE PARA PUBLICAÇÃO NO GITHUB PAGES

PUBLICAÇÃO:
1. Faça uma cópia de segurança do repositório atual.
2. No repositório GitHub Pages, substitua o index.html pelo deste pacote.
3. Envie também a pasta modelos/ completa, mantendo os nomes dos arquivos.
4. Faça commit das alterações e aguarde a atualização do GitHub Pages.
5. Teste no site os quatro botões de download em computador e celular.
